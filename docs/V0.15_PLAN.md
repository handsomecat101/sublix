## 3. Kỹ thuật

**Backend Rust — module mới `src-tauri/src/discovery/`** (mỗi file < 300 dòng, không `unwrap()`):
- `mod.rs` — kiểu `DiscoveryItem { id, platform, title, url, thumbnail_url, duration_sec, view_count, author, publish_time }` + lệnh Tauri `discovery_bilibili_popular / _ranking / _search`, `discovery_douyin_hot`, `discovery_youtube_search`.
- `bilibili.rs`, `douyin.rs`, `youtube.rs` — gọi HTTP bằng `reqwest` (đã có trong Cargo.toml) / chạy yt-dlp; **parser thuần tách riêng + test bằng JSON mẫu đã lưu** (không gọi mạng khi test).
- `cache.rs` — cache trong bộ nhớ: hot/xếp hạng 30 phút, hot words 15 phút, kết quả tìm 5 phút. Frontend debounce 500 ms.
- Tôn trọng nguồn: gọi tần suất thấp, User-Agent ghi rõ app, **không giả cookie/chữ ký**. Lỗi mạng/bị chặn ⇒ thông báo rõ tiếng Việt, không treo.
- Ảnh thu nhỏ Bilibili cần `Referer` ⇒ tải qua backend (hoặc proxy asset) — thợ xác minh.

**Frontend — `src/views/discovery/`** (component mới, không phình `DownloaderView.tsx` 1.700 dòng): ô tìm + chọn nguồn, hàng chip hot, lưới thẻ (ảo hoá khi > 100), trạng thái tải/ lỗi/ trống. **Opus thiết kế mockup trước** (Cinema Dark, tiếng Việt có dấu).

**Nấc C — trình duyệt nhúng:** cửa sổ Tauri thứ 2 mở trang ngoài. **Bảo mật bắt buộc:** trang ngoài **không** được gọi lệnh Tauri (capability chỉ cấp cho cửa sổ `main`/`overlay`). App đọc URL trang đang xem ⇒ nút "Tải video đang xem". Làm **spike 1 ngày** trước để xác nhận Douyin/TikTok chạy được trong WebView2.
